# Nexopoly

The web app for the NEXIS School of Business audit challenge: teams of three review a company's records in a Google Drive-style workspace, take notes, call in an expert, and submit a structured report that is graded by AI.

- [docs/PLAN.md](docs/PLAN.md): the full plan, the decisions behind it, and the architecture
- [docs/STATUS.md](docs/STATUS.md): what's built, how to run it, and the event-day checklist

Stack: Next.js 14 · TypeScript · Tailwind · Supabase (Postgres, Realtime, Storage) · Vercel · Claude Opus 5.5 for grading.
